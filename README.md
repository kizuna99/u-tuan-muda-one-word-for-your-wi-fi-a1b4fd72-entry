This entry's word is **Connected-ish** — the state every home Wi-Fi user knows: the phone proudly says "Connected" while nothing actually loads. `main.py` writes that single word to `/output/entry.txt`, deterministically, with no network, no randomness and no inputs, comfortably inside the gate of 1–20 characters.
